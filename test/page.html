quorb 多连接预览页（示例页面）

这是一个用于验证 quorb 悬浮球的本地测试页。mock 数据内置三条连接： 个人版（35%）、团队席位（20%）、旧团队（已过期演示 stale）。 右下角（或你上次停靠的位置）应当能看到一颗液态玻璃球：外环为所有参与连接中最紧的剩余百分比（应为 20，来源团队席位）。

验证清单

· 球体渲染并可拖拽，靠近屏幕边缘可磁吸停靠；悬浮提示按连接列出各自最紧百分比
· 侧边栏 / 面板：聚合 Hero = 20% + 三张连接卡，旧团队显示「数据过期」并带刷新链接
· 「连接 / 管理」进管理视图：启停 / 编辑 / 删除 / 排序 / 频率 / 球体关注均可用
· 「添加连接」向导的字段、提示、校验全部来自 configSchema（mock 的 glm 描述符）
