GLM 个人账号 · 真实解析预览

本页用 src/providers/glm.js 归一化一份个人账号的真实形态响应 （TOKENS_LIMIT 5 小时 / 周窗口 + TIME_LIMIT MCP 月度计数）， 再把结果交给真实的悬浮球 / 面板渲染。个人账号只填 API Key，组织 / 项目留空。

验证点

· 个人账号不需要组织 / 项目 ID，请求走「不带 type」的主路径
· TOKENS_LIMIT 的 5 小时 / 周窗口都应显示，百分比按「已用」换算为「剩余」
· TIME_LIMIT（MCP 月度计数）不得混入套餐窗口
· 无绝对用量字段时只显示剩余百分比，不出现「— / —」
